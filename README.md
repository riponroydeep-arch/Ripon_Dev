# Ripon Roy Portfolio

A static GitHub Pages portfolio website inspired by the agentic AI company hierarchy and cybernetic visual system described in the project brief.

## Files

- index.html — full portfolio page
- img/ — profile and reference images
- Agentic_AI_Company_Hierarchy.md — role hierarchy and design rationale
- Design Prompt — original creative brief

## GitHub Pages deployment

1. Push this folder to a GitHub repository.
2. In GitHub, go to the repository Settings.
3. Open Pages.
4. Set Source to Deploy from a branch.
5. Choose Branch: main or master, and Folder: /root.
6. Save.

Your site will be published at:

https://<your-username>.github.io/<your-repository-name>/

## Local preview

Open index.html directly in a browser, or run:

python -m http.server 8000

Then visit http://localhost:8000
